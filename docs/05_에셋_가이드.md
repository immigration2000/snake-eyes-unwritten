# 05. 에셋 가이드 (M5)

플레이스홀더를 실제 그림·음악으로 바꾸는 절차. **코드 수정 없음** — 파일을 넣고 `manifest.json` 만 갱신하면 된다.

## 규격

| 종류 | 게임 안 크기 | 생성 권장 크기 | 형식 | 위치 |
|---|---|---|---|---|
| 배경 `bg` | 960×540 | 1344×768 (SDXL) | PNG | `public/assets/bg/<key>.png` |
| 삽화 `cg` | 960×540 | 1344×768 | PNG | `public/assets/cg/<key>.png` |
| 타이틀 `ui` | 960×540 | 1344×768 | PNG | `public/assets/ui/title.png` |
| 스프라이트 `sprites` | 높이 52~100px (키별, `scripts/prep_assets.py` 의 `SPRITE_H`) · 발끝이 아래 중앙 | 832×1216 → 배경 제거 | 투명 PNG | `public/assets/sprites/<key>.png` |
| BGM `audio` | 30초~1분 루프 | — | MP3 | `public/assets/audio/<key>.mp3` |
| 효과음 `se` | 짧게 | — | MP3 | `public/assets/audio/se/<key>.mp3` |

키 목록 = `scripts/asset_prompts.json` 의 항목 이름 (배경 12 · 스프라이트 25 · CG 14 · 타이틀 1). BGM 키는 원본 §8 (`ch01`~`ch16`, `epilogue`, `main_theme`). 효과음 키는 스크립트에서 쓰는 것: `page`, `tear`, `dissolve`, `gate`, `wind`.

## 파이프라인

```
scripts/asset_prompts.json  ──gen_assets.py──▶  raw-assets/<종류>/<key>.png  ──prep_assets.py──▶  public/assets/… + manifest.json
       (프롬프트, §7 기준)        (diffusers, GPU)        (git 무시)               (리사이즈·배경 제거·등록)
```

### 1. 생성

```bash
python scripts/gen_assets.py --dry-run                # 프롬프트 확인만
python scripts/gen_assets.py --kind bg                 # 배경 12장
python scripts/gen_assets.py --kind cg --n 3           # CG 를 키당 3장 뽑아 고르기 (<key>_1.png …)
python scripts/gen_assets.py --kind sprites
python scripts/gen_assets.py --model Laxhar/noobai-XL-1.1
```

- 기본 모델 `OnomaAIResearch/Illustrious-xl-early-release-v0` (HF, 첫 실행 시 ~7GB 다운로드). 로컬 `.safetensors` 경로도 가능.
- `--n 3` 으로 뽑은 후보는 마음에 드는 것을 `<key>.png` 로 이름을 바꿔야 prep 단계에서 집는다.
- 다른 도구(WebUI, ComfyUI 등)로 뽑아도 됨 — `raw-assets/<종류>/<key>.png` 에 넣기만 하면 된다. 프롬프트는 `--dry-run` 출력을 복사.

### 2. 규격화 + 등록

```bash
pip install rembg          # 스프라이트 배경 제거 (한 번만)
python scripts/prep_assets.py
```

- 배경·CG·타이틀: 960×540 커버 크롭.
- 스프라이트: 배경 제거 → 투명 여백 트림 → 키별 높이로 축소. 이미 투명 PNG 면 `--no-rembg`.
- `manifest.json` 은 `public/assets/` 에 실제로 있는 파일 기준으로 다시 쓴다.
- 실행 후 `npm run dev` 로 확인. 배경이 실제 파일이면 플레이스홀더 나무 실루엣은 자동으로 안 그린다.

### 3. BGM · 효과음

mureka.ai 등에서 원본 §8 프롬프트로 생성 → `raw-assets/audio/<key>.mp3` (효과음은 `raw-assets/audio/se/`) → `prep_assets.py` 가 복사·등록. 볼륨은 설정 메뉴 기본값(BGM 70 / SE 80)에 맞춰 -14 LUFS 근처로 정규화하면 편하다.

## 일관성 규칙 (원본 §7-4)

1. **레드는 벨즈 전용.** 쌍둥이는 앰버(리사)/시안(미사).
2. 어린 벨즈(4~8장) = SFW, 완전 착의.
3. 쌍둥이 가면: 15장 `risa_bare`/`misa_bare` 만 맨얼굴.
4. 노아는 후드로 얼굴 가림.
5. 뽑은 뒤 레드·시안 그레이딩으로 세트감 통일 (Lightroom 등). prep 단계 전에 `raw-assets` 에서 보정.
6. OC(쌍둥이·노아·조연)는 모델이 모르므로 일관성이 필요하면 소형 LoRA (레퍼런스 10~20장).

## 우선순위

에셋이 다 없어도 게임은 돌아가므로 효과가 큰 것부터:

1. 배경 12장 — 화면의 대부분. 한 번에 뽑아도 20분 내외.
2. 벨즈 스프라이트 7종 (`baelz*`) + 쌍둥이 4종 + 노아.
3. ★ CG 8컷: `ch02_forest_child`, `ch05_escape`, `ch06_veil`, `ch07_unveiled`, `ch08_wish`, `ch11_name`, `ch13_two_faces`, `ch16_gift`.
4. 메인 테마 + `ch08` / `ch11` / `ch16` / `epilogue` BGM.
5. 나머지 CG·조연·BGM·효과음, 타이틀 아트.
