# 04. 챕터 스크립트 포맷

챕터 하나 = `src/data/chapters/chNN.json` 하나. 추가 후 `src/data/index.ts` 레지스트리에 등록하고 `npm run validate:script` 로 검사한다.

## 챕터 구조

```jsonc
{
  "id": "ch02",                 // 챕터 id. "chNN" 형식
  "part": 1,                    // 부 (1~5). HUD 라벨용
  "title": "숲의 아이",
  "bg": "forest",               // 시작 배경 키 (assets/bg/<key>.png)
  "bgm": "ch02",                // 시작 BGM 키 (선택)
  "world": { "width": 1400, "spawn": 80 },   // 없으면 VN 모드 (이동 없음)
  "entry": "start",             // 진입 시 자동 실행할 블록
  "triggers": [
    { "x": 700, "label": "meet", "auto": true, "once": true, "sprite": "baelz_child" },
    { "x": 1000, "label": "talk_misa", "once": true, "sprite": "misa", "hint": "미사에게 말 걸기" }
  ],
  "script": {
    "start": [ /* 명령 배열 */ ],
    "meet":  [ /* ... */ ]
  }
}
```

### 트리거

| 필드 | 설명 |
|---|---|
| `x` | 월드 x 좌표. 플레이어가 ±48px 안에 오면 활성 |
| `label` | 실행할 블록 |
| `auto` | `true` 면 접근 즉시 실행. 없으면 `[E]` 힌트 표시 후 키 입력 |
| `once` | `true` 면 한 번만 (세이브에 기록) |
| `sprite` | 그 자리에 세워 둘 캐릭터 스프라이트 키 |
| `hint` | `[E] 힌트` 문구 |

**챕터 끝**은 항상 월드 끝 근처에 `auto` 트리거를 두고 그 블록에서 `chapter` 명령으로 넘긴다.

## 명령 목록

| 명령 | 형태 | 설명 |
|---|---|---|
| 나레이션 | `{ "t": "n", "text": "..." }` | 이름표 없음 |
| 대사 | `{ "t": "s", "who": "baelz", "text": "..." }` | `who` 는 `config.ts` 의 `SPEAKERS` 키 |
| 선택지 | `{ "t": "choice", "options": [ { "text": "...", "goto": "label", "set": { "flag": "v" } } ] }` | 고르면 `set` 후 `goto` |
| 점프 | `{ "t": "goto", "label": "..." }` | 현재 블록 종료, 다른 블록 실행 |
| 플래그 | `{ "t": "set", "key": "...", "value": ... }` | 문자열/숫자/불리언 |
| 조건 | `{ "t": "if", "key": "...", "eq": ..., "goto": "..." }` | 같으면 점프, 아니면 다음 줄 |
| 배경 | `{ "t": "bg", "key": "ruin" }` | 페이드 아웃/인 |
| 삽화 | `{ "t": "cg", "key": "ch08_wish" }` / `{ "t": "cg", "key": null }` | 전체 화면 CG 표시 / 해제 |
| BGM | `{ "t": "bgm", "key": "ch08" }` / `null` | (M1 에서 실제 재생) |
| 침묵 | `{ "t": "pause", "ms": 1500 }` | 대화창 숨기고 대기. §9-5 침묵 연출 |
| 등장 | `{ "t": "show", "who": "risa", "at": "left" }` | `left` / `center` / `right` |
| 퇴장 | `{ "t": "hide", "who": "risa" }` | |
| 챕터 이동 | `{ "t": "chapter", "id": "ch03" }` | 페이드 후 다음 챕터. 블록 종료 |
| 종료 | `{ "t": "end" }` | 타이틀로. 엔딩 뒤에만 |

블록 끝에 도달하면(점프 없이) 대화창이 닫히고 조작이 돌아온다.

## 텍스트 규칙

- `{name}` → 플레이어 이름으로 치환. 소설의 "노아"는 전부 `{name}` 으로.
- `*...*` → 이탤릭 강조 (마음의 소리·테마 문장). 현재는 마커 제거만, M1 에서 레드 이탤릭.
- 한 명령의 텍스트는 **대화창 3줄(약 90자) 이내**. 소설 한 문단은 2~4개 `n` 으로 쪼갠다.
- 소설의 서술 속 대사(`"…" 하고 말했다`)는 `s` 로 꺼내고, 서술은 `n` 으로 남긴다.
- 감정 클라이맥스 앞뒤에 `pause`. 8·11·14·15장은 필수.

## 소설 → 스크립트 변환 절차

1. 원본 §4 의 해당 장을 읽고 **장면 단위**로 나눈다 (배경이 바뀌거나 시간이 흐르면 새 장면).
2. 탐색형이면 장면마다 트리거 하나(x 간격 400~600). 회상형이면 `entry` 하나에 전부.
3. 문단을 `n`/`s` 로 쪼갠다. 원문 문장을 바꾸지 않는다 — 원본이 최종 텍스트다.
4. 등장/퇴장 위치에 `show`/`hide`. 임팩트 컷에 `cg` (원본 §7-3 목록의 키).
5. 선택지는 원본 §6-1 표에 있는 것만. 임의로 늘리지 않는다.
6. `npm run validate:script` → 브라우저 확인 → 커밋.

## 화자 추가

`src/config.ts` 의 `SPEAKERS` 에 항목을 추가한다.

```ts
horn_boy: { name: "뿔 부러진 소년", color: PALETTE_CSS.bone, sprite: "horn_boy" },
```

- `color` — 이름표 색. **레드는 벨즈 계열에만.**
- `sprite` — `assets/sprites/<sprite>.png`. 없으면 플레이스홀더(`BootScene.makePlaceholders` 의 `chars` 에 실루엣 색 추가).
