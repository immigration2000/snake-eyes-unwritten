# 01. 게임 디자인 문서 (GDD)

> 원본 자료: [00_원본_통합자료.md](00_원본_통합자료.md). 이 문서는 그 자료를 **어떤 게임으로 만들 것인가**로 좁힌다.

## 1. 제목

**SNAKE EYES — 아무도 적지 않은 나라**
영문 부제: *The Unwritten Country*

- "SNAKE EYES" = 원작 MV 제목이자, 주사위 1·1(최악의 눈) — 뱀눈의 아이를 세상이 본 방식.
- "아무도 적지 않은 나라" = 세상 기록 어디에도 없는 나라 + 노아(기록자)가 처음으로 적는 나라. 노아의 노트 = 게임 자체.

## 2. 한 줄 정의

**산나비처럼 걷고, 비주얼 노벨처럼 읽는 90분짜리 다크 페어리테일.**

- 플레이어는 후드를 쓴 기록자 **노아**(이름 입력 가능)가 되어 숨은 나라를 걸으며 사람들과 이야기한다.
- 전투·퍼즐·실패 없음. 게임의 "행동"은 **걷기 · 말 걸기 · 선택하기 · 기록하기** 네 가지.
- 감정의 핵심은 지연 공개 — 숲에서 반나절 놀아 준 아이가 전설의 마왕이었다는 것.

## 3. 왜 이 형식인가 (산나비 참조)

| 산나비에서 가져올 것 | 이 게임에서의 형태 |
|---|---|
| 픽셀아트 + 시네마틱 연출 | 960×540 픽셀 캔버스, 챕터 타이틀 카드, 페이드, 침묵 연출 |
| 걷기만으로 서사가 진행되는 구간 | 사이드스크롤 월드 + 위치 트리거(자동 나레이션) |
| 감정 클라이맥스에서 조작을 뺏는 연출 | 스크립트 실행 중 이동 잠금, CG 컷 |
| 짧고 강한 대사 | 원작 소설의 절제된 톤을 그대로 사용 |
| 가져오지 않을 것 | 액션·갈고리·전투. 우리는 "걷는 소설"이다. |

## 4. 핵심 루프

```
[챕터 진입] → 타이틀 카드 → entry 스크립트(도입 나레이션)
   ↓
[탐색] 좌우로 걷는다 → 트리거 근처 → 자동 재생 or [E] 말 걸기
   ↓
[대화] 대사·나레이션 → (선택지) → 플래그 기록
   ↓
[챕터 끝 트리거] → 다음 챕터 (자동 세이브)
```

챕터당 3~6개 트리거. 자동 트리거 = 나레이션(걷다 보면 흘러나옴), 수동 트리거 = 사람에게 말 걸기(선택).

## 5. 씬 구성

원본 §5-1 표를 따른다. 씬 유형은 셋:

| 유형 | 설명 | 해당 챕터 |
|---|---|---|
| **탐색형** | 사이드스크롤 월드, 트리거 여러 개 | 1, 3, 9, 10, 11 |
| **회상형** | 월드 없음(VN 모드). 배경+스프라이트+CG, 순차 재생 | 4, 5, 6, 7, 8 |
| **대치/정적형** | 월드는 있으나 한 장소. 연출 중심, 이동 거의 없음 | 2, 12, 13, 14, 15, 16, 에필 |

**부 II 회상 해금 방식**: 3장 이후 나라 안 트리거(리사의 옛이야기 / 미사의 행간 / 폐허의 유물)에 말을 걸면 4~8장이 순서대로 열린다. 첫 구현은 순차 재생, 해금 UI는 M4 이후 선택 사항.

## 6. 선택과 엔딩

원본 §6 그대로.

| 선택 | 챕터 | 플래그 | 영향 |
|---|---|---|---|

| 놀이 종류 | 2 | `ch02_play` | 그 씬 대사만 |
| 자기 소개 | 12 | `ch12_intro` | 그 씬 대사만 |
| **몰살 고백 응답** | **14** | **`ending` = `pity` / `respect` / `awe`** | 에필로그 마무리 3분기 |

히든 조건(선택): 부 III 트리거 전부 읽기 → 에필로그 조약돌 추가 씬. 플래그 `pebble`.

## 7. 연출 규칙 (요약)

- **팔레트**: 잉크 `#08080b`, 본 `#ece3dd`, 벨즈 레드 `#ff2c3d`(벨즈 전용), 리사 앰버 `#f5b13a`, 미사 시안 `#46d6e3`.
- **일상 = 웜, 진실 = 콜드**. 13장은 레드→시안 전환. 15장은 거의 암전.
- **침묵**: 8·11·14·15장 핵심 순간은 `pause` 명령으로 대화창을 지우고 화면만 남긴다.
- **이탤릭 `*...*`**: 마음의 소리·테마 문장. 레드 톤 이탤릭으로 렌더 (M1).
- **가면 규칙**: 15장에서만 쌍둥이 맨얼굴 스프라이트.

## 8. 플레이어 아바타

- 이름 입력(기본 "노아"). 텍스트 내 `{name}` 치환.
- 후드로 얼굴 가림. 성별 언급 없음. 대사는 관찰형·절제.

## 9. 범위 밖 (하지 않을 것)

- 전투, 점프 퍼즐, 인벤토리, 호감도 수치 UI.
- 음성. (BGM/SE 만)
- 다국어. (한국어 우선. 영어는 텍스트 구조상 가능하나 로드맵 밖)
